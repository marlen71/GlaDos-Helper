# Голосовой помощник

Локальный голосовой помощник для Windows. Слушает микрофон, ждёт обращения по
имени, выполняет команду и отвечает синтезированным голосом.

Работает офлайн — интернет нужен только при установке, чтобы скачать модели.

```
Вы:      Гладос, включи Discord
Помощник: Хорошо, сию секунду, сэр, запускается.

Вы:      Гладос, сколько время?
Помощник: Время девятнадцать часов пятнадцать минут, сэр.

Вы:      Гладос, напомни выпить воды завтра в 08:00
Помощник: Хорошо, слушаюсь, сэр. Напомню 24.09.2026 в восемь часов ровно.
```

Имя настраивается — можно назвать помощника как угодно.

---

## Установка

Нужен **Python 3.10–3.12** ([скачать](https://www.python.org/downloads/),
при установке отметить «Add Python to PATH») и около 3 ГБ на диске.

1. Запустите **`install.bat`**.
2. Выберите вариант установки — обычный или с ускорением на видеокарте.
3. Запустите **`mictest.bat`** и проверьте, что микрофон слышит вас исправно.
4. Запустите **`run.bat`**.

---

## Файлы для запуска

| Файл | Назначение |
|---|---|
| `run.bat` | запустить помощника |
| `mictest.bat` | проверка микрофона и распознавания |
| `check.bat` | диагностика: пакеты, устройства, видеокарта |
| `install.bat` | установка и обновление |
| `config.yaml` | все настройки |

Дополнительные режимы запуска:

```bat
run.bat --text               печатать команды вместо голоса (проверка настроек)
run.bat --say "Проверка"     произнести фразу
run.bat --devices            список микрофонов
```

## Команды

Фраза начинается с имени помощника. В течение 10 секунд после ответа можно
продолжать без обращения.

**Программы и игры**

| Скажите | Действие |
|---|---|
| «открой браузер» | запуск браузера |
| «открой ютуб» | открыть YouTube |
| «включи стим» | запуск Steam |
| «включи дискорд» | запуск Discord |
| «открой телеграм» | запуск Telegram |
| «включи музыку» | запуск Яндекс Музыки |
| «открой проводник» | открыть проводник |
| «открой игру Гаррис Мод» | запуск игры через Steam |

Глаголы взаимозаменяемы: *открой, включи, запусти, врубай*.

**Время, заметки, напоминания**

| Скажите | Действие |
|---|---|
| «сколько время?» | назовёт время |
| «какая сегодня дата?» | назовёт дату |
| «запиши в заметки купить молоко» | запись в `data/notes.md` |
| «запиши в заметки ссылку из буфера обмена» | сохранит скопированное |
| «прочитай заметки» | зачитает последние записи |
| «напомни выпить воды завтра в 9» | напоминание |
| «напомни через 20 минут вынуть пиццу» | напоминание |
| «какие напоминания?» | список активных |

**Управление компьютером**

| Скажите | Действие |
|---|---|
| «выключи компьютер» | выключение с подтверждением |
| «перезагрузи компьютер» | перезагрузка с подтверждением |
| «отмена» | отменить выключение |
| «выключись» | закрыть помощника |

## Настройка

Всё в файле **`config.yaml`**. После изменений перезапустите `run.bat`.

### Имя и обращение

```yaml
user:
  name: "Марлен"        # ваше имя
  title: "сэр"          # обращение, можно оставить пустым
  birthday: "10.11"     # ДД.ММ — поздравит в этот день

wake:
  words: ["гладос", "глэдос", "glados"]   # имя помощника
  fuzzy: true                             # распознавать похожие по звучанию
```

Чтобы сменить имя, замените список. Например для «Джарвис»:

```yaml
wake:
  words: ["джарвис", "jarvis"]
```

Перечислять искажённые варианты не нужно — похожие по звучанию слова
распознаются автоматически.

### Программы и игры

```yaml
apps:
  steam: "C:/Program Files (x86)/Steam/steam.exe"
  obs: "C:/Program Files/obs-studio/bin/64bit/obs64.exe"

games:
  "халф лайф": 220                              # Steam AppID
  "майнкрафт": "C:/Games/Minecraft/launcher.exe" # или путь к файлу
```

AppID — число в адресе страницы игры в Steam:
`store.steampowered.com/app/`**`4000`**`/Garrys_Mod/`

Слева пишите так, как произносите название вслух.

### Голос

```yaml
tts:
  speaker: "xenia"    # baya / kseniya / xenia / aidar / eugene
  glados_effect:
    enabled: true
    pitch_semitones: -1.5   # ниже 0 — грубее
    robot_depth: 0.35       # металличность: 0.1 почти живой, 0.6 робот
    reverb: 0.22            # эхо
```

Послушать результат, не запуская помощника:

```bat
run.bat --say "Проверка связи"
```

## Если плохо распознаёт речь

Сначала запустите **`mictest.bat`** — он измерит шум, громкость голоса и
покажет, что именно слышит система.

**Помощник не реагирует на имя.** Убедитесь, что в `config.yaml` стоит
`model: "small"` или крупнее. Модели `tiny` и `base` часто путают имя.

**Обрывает фразу на середине.** Увеличьте паузу:

```yaml
stt:
  silence_seconds: 1.0    # не ставьте меньше 0.5
```

**Не слышит совсем.** Уменьшите требование к громкости:

```yaml
stt:
  threshold_multiplier: 2.0
```

Если микрофон тихий — добавьте усиление `gain: 2.0` и проверьте громкость
в *Параметры → Система → Звук → Ввод*.

**Реагирует на посторонний шум.** Увеличьте `threshold_multiplier` до `4.5`.
Используйте наушники, чтобы ответы помощника не попадали обратно в микрофон.

**Нужно выбрать конкретный микрофон.** Посмотрите номер в `mictest.bat` и
укажите его:

```yaml
stt:
  device_index: 1
```

## Скорость ответа

| Модель | На процессоре | Точность |
|---|---|---|
| `base` | ~0.7 с | часто путает имя |
| `small` | ~1.5 с | рекомендуется |
| `medium` | ~4 с | высокая |
| `large-v3` | ~10 с | максимальная |

С видеокартой NVIDIA любая модель отвечает почти мгновенно. Для включения
запустите `install-gpu.bat` и проверьте результат через `check.bat`.

## Если что-то не работает

**Пакет не найден** (`ModuleNotFoundError`) — запустите `install.bat` заново.

**Батник выдаёт странные ошибки** — скачайте проект заново либо запустите
установку напрямую: `python setup_glados.py`.

**Не запускается программа** — проверьте путь в `config.yaml`. Удобно
проверять командой `run.bat --text`.

**Голос звучит неразборчиво** — уменьшите `robot_depth` до `0.15` или
отключите эффект: `glados_effect.enabled: false`.
