# GLaDOS Helper 🧪

Голосовой ассистент для Windows в стиле **GLaDOS** из Portal 2 — как Джарвис, только с
сарказмом Aperture Science. Работает **полностью офлайн**.

```
Вы: Гладос, привет!
GLaDOS: Добрый вечер, сэр Марлен! Чем могу помочь?

Вы: Гладос, включи Discord
GLaDOS: Хорошо, сию секунду, сэр, запускается.

Вы: Гладос, сколько время?
GLaDOS: Время девятнадцать часов пятнадцать минут, сэр.

Вы: Гладос, запиши в заметки ссылку из буфера обмена
GLaDOS: Хорошо, сэр! Записала из буфера обмена.

Вы: Гладос, напомни принять таблетку и выпить водички 23.09.2026 в 08:00
GLaDOS: Хорошо, слушаюсь, сэр. Напомню 23.09.2026 в восемь часов ровно: принять таблетку и выпить водички.

Вы: Гладос, какая сегодня дата?
GLaDOS: Сегодня двадцать второе сентября две тысячи двадцать шестого года, сэр.
        (а 10 ноября: «...ваш день рождения, сэр Марлен. Поздравляю вас.»)
```

## Как устроено

| Слой | Технология |
|---|---|
| Распознавание речи | **faster-whisper** (офлайн, русский) + энергетический VAD |
| Синтез речи | **Silero TTS v4 ru** + собственная цепочка эффектов «голос GLaDOS» |
| Эффект голоса | pitch-shift → ring-modulation → flanger → soft-drive → reverb (`glados/audio_fx.py`) |
| Навыки | приложения/игры, питание ПК, время/дата, заметки, напоминания |

> Почему не [R2D2FISH/glados-tts](https://github.com/R2D2FISH/glados-tts) напрямую:
> та модель обучена **только на английском** и русский текст произносит нечитаемо.
> Здесь русский голос Silero прогоняется через DSP-цепочку, дающую характерный
> металлически-холодный тембр GLaDOS. Параметры эффекта настраиваются в `config.yaml`.

## Установка (Windows)

1. Установите **Python 3.10+** (галочка «Add Python to PATH»).
2. Запустите `install.bat` — создаст окружение и поставит всё нужное (~2 ГБ, torch CPU).
3. Откройте `config.yaml` и проверьте имя, пути к Steam/Discord, список игр.
4. Запустите `run.bat`.

Первый запуск скачает модели (Silero ~60 МБ, Whisper small ~460 МБ) — потом всё локально.

## Режимы запуска

```bat
run.bat                      :: голосовой режим
run.bat --text               :: текстовый режим (отладка, без микрофона)
run.bat --voice-text         :: печатаете — Гладос отвечает голосом
run.bat --say "Тест системы" :: просто озвучить фразу
run.bat --demo demo.wav      :: сохранить пример голоса в файл
run.bat --devices            :: список микрофонов/динамиков
check.bat                    :: диагностика окружения и аудиоустройств
```

Если батники по какой-то причине не работают, всё то же самое напрямую:

```bat
python setup_glados.py                    :: установка
.venv\Scripts\python.exe main.py          :: запуск
.venv\Scripts\python.exe check.py         :: диагностика
```

## Команды

| Что сказать | Что делает |
|---|---|
| «Гладос, привет» | приветствие с учётом времени суток |
| «Гладос, открой браузер / ютуб / стим / дискорд / телеграм / проводник» | запуск приложения или сайта |
| «Гладос, открой игру Портал 2» | запуск через `steam://rungameid/<AppID>` |
| «Гладос, сколько время?» | время прописью |
| «Гладос, какая сегодня дата?» | дата прописью (+ поздравление в ваш ДР) |
| «Гладос, запиши в заметки ...» / «... ссылку из буфера обмена» | → `data/notes.md` |
| «Гладос, прочитай заметки» | последние 5 заметок |
| «Гладос, напомни <что> <когда>» | 23.09.2026 в 08:00 / завтра в 9 / через 10 минут |
| «Гладос, какие напоминания?» | список активных |
| «Гладос, выключи компьютер» / «перезагрузи компьютер» | с подтверждением и таймером |
| «Гладос, отмена» | отменяет запланированное выключение |
| «Гладос, выключись» | завершает работу ассистента |

После ответа 10 секунд можно говорить **без** слова активации (настройка `wake.followup_seconds`).

## Настройка

Всё в `config.yaml`:

* `user` — имя, обращение («сэр»), дата рождения;
* `wake.words` — варианты слова активации (Whisper иногда слышит «глэдос», «гладис»);
* `stt.model` — `tiny`…`large-v3`; `small` — хороший баланс, `medium` точнее но медленнее;
* `stt.vad_threshold` — поднимите, если Гладос реагирует на шум; опустите, если не слышит;
* `tts.glados_effect` — сила роботизации (`robot_depth`), эхо (`reverb`), тон (`pitch_semitones`);
* `apps` — пути к программам; `games` — «как говорю» → Steam AppID или путь к exe.

Добавить игру:
```yaml
games:
  "халф лайф": 220
  "мой лаунчер": "D:/Games/launcher.exe"
```

## Если что-то не работает

* **Батник ругается `'Создаю' is not recognized...`** → файлы `.bat` скачались с
  Unix-переводами строк. Скачайте архив заново (в репозитории есть `.gitattributes`,
  который принудительно отдаёт `.bat` в формате CRLF) или запустите установку напрямую:
  ```bat
  python setup_glados.py
  ```
* **`ModuleNotFoundError: No module named 'faster_whisper'`** (или другого пакета) →
  установка не доехала до конца. Запустите `install.bat` заново и дождитесь надписи
  «Готово», либо доставьте руками:
  ```bat
  .venv\Scripts\python.exe -m pip install -r requirements.txt
  ```
  Проверить состояние окружения целиком: `.venv\Scripts\python.exe check.py`

* **Не слышит** → `run.bat --devices`, выберите микрофон по умолчанию в Windows, снизьте `vad_threshold`.
* **Реагирует на музыку** → повысьте `vad_threshold` до 0.03–0.05.
* **Голос слишком «роботный»** → уменьшите `robot_depth` до 0.15–0.2.
* **Медленно распознаёт** → поставьте `stt.model: base` или CUDA-версию torch и `device: cuda`.
* **Не ставится torch** → Гладос автоматически переключится на встроенный синтез Windows (SAPI), но без фирменного тембра.
