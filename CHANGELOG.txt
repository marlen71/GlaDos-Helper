[0.6.0] — 23.09.2026
--------------------------------------------------------------------------------
! ГЛАВНОЕ: сильно улучшено распознавание речи.

  Причина проблем была в трёх местах:

  1. Терялся первый слог. Запись начиналась только ПОСЛЕ того, как громкость
     превысила порог, поэтому начало слова просто не попадало в запись —
     отсюда «Ладас» и «Адос» вместо «Гладос».
     + Добавлен кольцевой пред-буфер на 0.5 секунды: в запись всегда попадает
       звук, произнесённый ДО срабатывания детектора.

  2. Обрубался конец слова. Порог включения и выключения был один и тот же,
     а окончания слов произносятся тише — «-ос» в «Гладос» терялось.
     + Добавлен гистерезис: порог отпускания на 45% ниже порога срабатывания.

  3. Настройка silence_seconds: 0.12 разрывала фразу на первой же паузе.
     Команда «Гладос, открой Discord» распадалась на два обрывка.
     + Значение по умолчанию 0.8 с, в конфиге явное предупреждение не ставить
       меньше 0.5.

+ Автоматическая подстройка под уровень шума (stt.auto_threshold).
  Порог срабатывания теперь вычисляется как «шум × множитель» и подстраивается
  на ходу. Одна настройка работает и в тишине, и при гудящем кулере.

+ Нормализация громкости перед распознаванием: тихая речь усиливается до
  рабочего уровня. Раньше тихий микрофон означал плохое распознавание.

+ Подсказка словаря для распознавания (initial_prompt): модели передаётся
  список ожидаемых слов — имя помощника, команды, названия игр. Это заметно
  снижает число замен незнакомого имени на похожие обычные слова.

+ Отключён повторный VAD внутри faster-whisper: он обрезал короткие фразы,
  которые уже были корректно выделены собственным детектором.

+ НЕЧЁТКОЕ РАСПОЗНАВАНИЕ ИМЕНИ (glados/fuzzy.py).
  Перечислять варианты произношения вручную больше не нужно. Используется
  фонетический код для кириллицы плюс расстояние Левенштейна.
  Проверено: «лада», «ладас», «ладос», «складас», «владас», «сладость»,
  «кладос», «клады», «адос», «глада», «гладис», «глэдос» — распознаются как
  обращение, при этом обычные слова («игру», «ладно», «открой», «музыку»)
  ложных срабатываний не дают.
  Работает с любым именем: «Джарвис» ловится и как «жарвис».

+ Распознаётся имя, слипшееся с командой: «гладосвключи дискорд».

+ НОВЫЙ ИНСТРУМЕНТ: mictest.bat — проверка микрофона в четыре шага.
    1. список устройств записи и выбранное по умолчанию;
    2. замер фонового шума за 3 секунды с оценкой (отлично/хорошо/шумно);
    3. замер громкости речи и отношения сигнал/шум с конкретными советами;
    4. проверка распознавания: показывает, что именно услышала система
       и было ли найдено имя.
  В конце выводится вердикт «система слышит вас исправно» либо перечень
  проблем с указанием, что исправить.

+ Новые настройки в config.yaml:
    stt.device_index          выбор конкретного микрофона по номеру
    stt.gain                  усиление тихого микрофона
    stt.auto_threshold        автоподстройка под шум
    stt.threshold_multiplier  во сколько раз речь громче шума
    stt.prompt                своя подсказка словаря
    wake.fuzzy                нечёткое распознавание имени

* Размер аудиоблока уменьшен с 1024 до 512 отсчётов (64 мс -> 32 мс):
  точнее засекается начало речи.
* Очередь микрофона очищается после ответа — помощник не слушает свой голос.
* Короткие щелчки и стуки больше не принимаются за фразу.
* README переписан в минималистичном виде.
! Исправлено произношение даты: «двадцать третье сентября» вместо
  «двадцать три сентября».
* Тесты: 52 -> 101. Добавлены проверки пред-буфера, гистерезиса, нормализации
  громкости, адаптации к шуму и полный набор вариантов произношения имени.


[0.5.1] — 23.09.2026
--------------------------------------------------------------------------------
! ГЛАВНОЕ: ускорение GPU не включалось, даже когда библиотеки CUDA были
  установлены. В логе было: "рабочие CUDA-библиотеки не найдены", хотя pip
  сообщал "Requirement already satisfied: nvidia-cublas-cu12".

  Причина: пакеты nvidia-cublas-cu12 и nvidia-cudnn-cu12 кладут DLL не в
  системные папки, а внутрь .venv\Lib\site-packages\nvidia\<пакет>\bin.
  Windows в этих папках библиотеки не ищет, поэтому ctranslate2 их не находил.
  Старая проверка звала ctypes.CDLL("cublas64_12.dll") напрямую и получала
  отказ, хотя файл лежал на диске.

  Что сделано:
    + новый модуль glados/cuda_setup.py: находит все папки с DLL внутри
      pip-пакетов nvidia-* и регистрирует их через os.add_dll_directory
      и PATH ДО первого обращения к faster-whisper;
    + подключение выполняется автоматически при импорте glados.stt;
    + учитывается, что cuDNN 9.x разбит на несколько файлов с разными именами.

! Установщик не предлагал пункт "Установка с ускорением GPU" владельцам
  видеокарт, для которых nvidia-smi не печатает строку "CUDA Version"
  (наблюдалось на GTX 1660). Теперь неизвестная версия драйвера считается
  подходящей: карта есть, а реальную работоспособность всё равно проверяет
  отдельная диагностика. Ложный отказ молча лишал человека ускорения.

! Исправлено обрезание названия видеокарты: "NVIDIA GeForce GTX 1660 SUPER"
  определялось неполностью из-за разбора по двум пробелам.

+ После установки CUDA установщик сразу проверяет, заработало ли ускорение,
  и при неудаче объясняет вероятную причину (старый драйвер, нужна
  перезагрузка), не прерывая установку.

+ В config.yaml теперь пишется device: "cuda" ТОЛЬКО если ускорение реально
  заработало. Раньше параметр прописывался по факту установки пакетов, и при
  каждом запуске сыпалось предупреждение с откатом на процессор.

+ Установщик предупреждает, если выбранная модель не влезет в видеопамять
  (например, large-v3 требует ~4 ГБ, а на карте 6 ГБ — впритык с системой).

+ check.bat теперь показывает, ГДЕ именно найдены библиотеки CUDA и почему
  ускорение не работает, вместо безликого "недоступно".

+ Предупреждение при Python 3.13+ : часть библиотек под свежие версии ещё
  не собрана, рекомендуется Python 3.12.

* Тесты: 40 -> 52. Добавлены регрессии на реальную раскладку pip-пакетов
  nvidia-*, на вывод nvidia-smi без версии CUDA и на полное имя GTX 1660.


[0.5.0] — 23.09.2026
--------------------------------------------------------------------------------
+ УСТАНОВЩИК ПОЛНОСТЬЮ ПЕРЕРАБОТАН: теперь он сканирует систему и позволяет
  выбрать, что именно ставить.

  При запуске install.bat показывается отчёт:
    - версия Python, свободное место, объём оперативной памяти;
    - модель видеокарты NVIDIA, объём видеопамяти и версия CUDA у драйвера;
    - найденный микрофон;
    - список уже установленных компонентов с пометками [✓].

  Затем предлагается меню:
    1. Базовая установка (процессор)
    2. Установка с ускорением GPU   — пункт появляется ТОЛЬКО если найдена
                                      подходящая видеокарта NVIDIA
    3. Выборочно — по каждому компоненту задаётся отдельный вопрос
    4. Только проверить, ничего не устанавливать
    5. Починить: переустановить сломанное

+ Умный выбор модели распознавания: показывается размер каждой модели и
  ожидаемая скорость ответа именно для вашей конфигурации (для GPU пишется
  "мгновенно", для CPU — реальные секунды). Модели, которые не влезут в
  видеопамять, помечаются.

+ Повторная установка больше ничего не ломает и не качает заново: каждый
  компонент проверяется перед установкой (наличие модуля, реальная
  загружаемость DLL, наличие файлов моделей на диске). Если всё на месте —
  установщик так и скажет: "Нечего устанавливать".

+ Модели скачиваются на этапе установки, а не при первом запуске. Раньше
  человек запускал Гладос и сидел минуту перед молчащей программой, пока
  качался Whisper.

+ После установки config.yaml правится автоматически: прописываются device,
  compute_type и выбранная модель. Руками YAML редактировать больше не нужно.

+ Ключи командной строки для install.bat:
    --auto     определить железо и поставить оптимальный вариант без вопросов
    --gpu      сразу с ускорением GPU
    --cpu      сразу без GPU
    --check    только показать отчёт
    --repair   переустановить сломанное
    --model X  указать модель распознавания

+ Новый файл install-gpu.bat — установка с ускорением в один щелчок.
+ Новый модуль glados/sysinfo.py: определение железа, проверка пакетов,
  поиск скачанных моделей. Используется и установщиком, и диагностикой.
* check.bat теперь показывает сводку установщика и подробную диагностику,
  включая модель видеокарты и подсказку, чем именно ставить CUDA.
* Тесты: 24 -> 40 (добавлен разбор вывода nvidia-smi для разных драйверов,
  подбор моделей под объём видеопамяти, логика планирования установки).


[0.4.0] — 23.09.2026
--------------------------------------------------------------------------------
! ГЛАВНОЕ: исправлено падение с ошибкой "RuntimeError: Library cublas64_12.dll
  is not found or cannot be loaded".
  Причина: в config.yaml был выставлен stt.device: "cuda", но в системе
  отсутствовали библиотеки CUDA (cuBLAS/cuDNN). faster-whisper загружал модель
  без ошибки, а падал уже при первом распознавании — потому что segments
  является ленивым генератором, и реальные вычисления начинались только при
  переборе.
  Что сделано:
    + функция cuda_is_usable() — перед запуском реально проверяет наличие
      CUDA-устройства И загружаемость cublas64_12.dll / cudnn_ops64_9.dll;
    + если в конфиге указан "cuda", но библиотек нет — выводится понятное
      предупреждение и работа продолжается на процессоре (без падения);
    + если CUDA отваливается уже во время распознавания — модель на лету
      перезагружается на CPU, ассистент продолжает работать без перезапуска;
    + любая другая ошибка распознавания больше не роняет программу: пишется
      в лог, Гладос просто ждёт следующую фразу.

! Исправлена автоподстановка типа вычислений: int8 на GPU и float16 на CPU
  больше не приводят к ошибкам — значение корректируется автоматически.

! Исправлен разбор даты в напоминаниях: при явно названной дате
  ("напомни ... 23.09.2026 в 08:00", когда время уже прошло) напоминание
  больше не переносится ошибочно на следующий день. Перенос на завтра теперь
  срабатывает только если названо ОДНО время без даты.

+ Добавлено приложение: Яндекс Музыка.
  Команды: "открой яндекс музыку", "включи музыку".
+ Добавлены игры:
    Garry's Mod  — 4000    ("гаррис мод", "гарис мод", "гмод", "garry's mod")
    CS:GO        — 4465480 ("ксго", "кс го", "csgo")
    CS 1.6       — 10      ("кс 1.6", "кс 1 6", "контра 1.6")
+ Новый параметр stt.beam_size (1 = быстро, 5 = точнее).
+ В check.py добавлена проверка доступности GPU с объяснением результата.
* Распознавание приложений теперь учитывает длину названия — составные имена
  ("яндекс музыку") срабатывают раньше коротких совпадений.
* config.yaml подробно прокомментирован: указана примерная задержка ответа
  для каждой модели Whisper, чтобы было понятно, чем платить за скорость.
* README полностью переписан: описание, установка, настройка, все команды,
  таблицы скорости, решение проблем.
+ Добавлен этот файл истории изменений.
* Тесты: 14 -> 24.
