[0.5.0] — 23.09.2026
--------------------------------------------------------------------------------
+ УСТАНОВЩИК ПОЛНОСТЬЮ ПЕРЕРАБОТАН: теперь он сканирует систему и позволяет
  выбрать, что именно ставить.

  При запуске install.bat показывается отчёт:
    - версия Python, свободное место, объём оперативной памяти;
    - модель видеокарты NVIDIA, объём видеопамяти и версия CUDA у драйвера;
    - найденный микрофон;
    - список уже установленных компонентов с пометками [✓].

  Затем предлагается меню:
    1. Базовая установка (процессор)
    2. Установка с ускорением GPU   — пункт появляется ТОЛЬКО если найдена
                                      подходящая видеокарта NVIDIA
    3. Выборочно — по каждому компоненту задаётся отдельный вопрос
    4. Только проверить, ничего не устанавливать
    5. Починить: переустановить сломанное

+ Умный выбор модели распознавания: показывается размер каждой модели и
  ожидаемая скорость ответа именно для вашей конфигурации (для GPU пишется
  "мгновенно", для CPU — реальные секунды). Модели, которые не влезут в
  видеопамять, помечаются.

+ Повторная установка больше ничего не ломает и не качает заново: каждый
  компонент проверяется перед установкой (наличие модуля, реальная
  загружаемость DLL, наличие файлов моделей на диске). Если всё на месте —
  установщик так и скажет: "Нечего устанавливать".

+ Модели скачиваются на этапе установки, а не при первом запуске. Раньше
  человек запускал Гладос и сидел минуту перед молчащей программой, пока
  качался Whisper.

+ После установки config.yaml правится автоматически: прописываются device,
  compute_type и выбранная модель. Руками YAML редактировать больше не нужно.

+ Ключи командной строки для install.bat:
    --auto     определить железо и поставить оптимальный вариант без вопросов
    --gpu      сразу с ускорением GPU
    --cpu      сразу без GPU
    --check    только показать отчёт
    --repair   переустановить сломанное
    --model X  указать модель распознавания

+ Новый файл install-gpu.bat — установка с ускорением в один щелчок.
+ Новый модуль glados/sysinfo.py: определение железа, проверка пакетов,
  поиск скачанных моделей. Используется и установщиком, и диагностикой.
* check.bat теперь показывает сводку установщика и подробную диагностику,
  включая модель видеокарты и подсказку, чем именно ставить CUDA.
* Тесты: 24 -> 40 (добавлен разбор вывода nvidia-smi для разных драйверов,
  подбор моделей под объём видеопамяти, логика планирования установки).


[0.4.0] — 23.09.2026
--------------------------------------------------------------------------------
! ГЛАВНОЕ: исправлено падение с ошибкой "RuntimeError: Library cublas64_12.dll
  is not found or cannot be loaded".
  Причина: в config.yaml был выставлен stt.device: "cuda", но в системе
  отсутствовали библиотеки CUDA (cuBLAS/cuDNN). faster-whisper загружал модель
  без ошибки, а падал уже при первом распознавании — потому что segments
  является ленивым генератором, и реальные вычисления начинались только при
  переборе.
  Что сделано:
    + функция cuda_is_usable() — перед запуском реально проверяет наличие
      CUDA-устройства И загружаемость cublas64_12.dll / cudnn_ops64_9.dll;
    + если в конфиге указан "cuda", но библиотек нет — выводится понятное
      предупреждение и работа продолжается на процессоре (без падения);
    + если CUDA отваливается уже во время распознавания — модель на лету
      перезагружается на CPU, ассистент продолжает работать без перезапуска;
    + любая другая ошибка распознавания больше не роняет программу: пишется
      в лог, Гладос просто ждёт следующую фразу.

! Исправлена автоподстановка типа вычислений: int8 на GPU и float16 на CPU
  больше не приводят к ошибкам — значение корректируется автоматически.

! Исправлен разбор даты в напоминаниях: при явно названной дате
  ("напомни ... 23.09.2026 в 08:00", когда время уже прошло) напоминание
  больше не переносится ошибочно на следующий день. Перенос на завтра теперь
  срабатывает только если названо ОДНО время без даты.

+ Добавлено приложение: Яндекс Музыка.
  Команды: "открой яндекс музыку", "включи музыку".
+ Добавлены игры:
    Garry's Mod  — 4000    ("гаррис мод", "гарис мод", "гмод", "garry's mod")
    CS:GO        — 4465480 ("ксго", "кс го", "csgo")
    CS 1.6       — 10      ("кс 1.6", "кс 1 6", "контра 1.6")
+ Новый параметр stt.beam_size (1 = быстро, 5 = точнее).
+ В check.py добавлена проверка доступности GPU с объяснением результата.
* Распознавание приложений теперь учитывает длину названия — составные имена
  ("яндекс музыку") срабатывают раньше коротких совпадений.
* config.yaml подробно прокомментирован: указана примерная задержка ответа
  для каждой модели Whisper, чтобы было понятно, чем платить за скорость.
* README полностью переписан: описание, установка, настройка, все команды,
  таблицы скорости, решение проблем.
+ Добавлен этот файл истории изменений.
* Тесты: 14 -> 24.


[0.3.0] — 22.09.2026
--------------------------------------------------------------------------------
! Исправлены .bat-файлы: были сохранены с Unix-переводами строк (LF), из-за
  чего Windows cmd выдавал ошибки вида "'Создаю' is not recognized as an
  internal or external command". Теперь все батники строго ASCII + CRLF.
! Исправлена кодировка вывода: русский текст в консоли Windows (cp866)
  больше не превращается в "кракозябры" — потоки переключаются на UTF-8.
+ Добавлен .gitattributes (*.bat text eol=crlf) — чтобы проблема не вернулась
  после клонирования репозитория.
+ Логика установки вынесена в setup_glados.py (Python вместо хрупкого .bat).
+ Добавлен check.bat — диагностика окружения в один клик.
* install.bat больше не зависит от activate.bat: пакеты ставятся напрямую
  через .venv\\Scripts\\python.exe -m pip, каждый шаг проверяется на ошибки.

[0.1.0] — 22.09.2026 — первый выпуск
--------------------------------------------------------------------------------
+ Голосовой ассистент GLaDOS, работающий полностью офлайн.
+ Распознавание речи: faster-whisper + энергетический детектор голоса.
+ Синтез речи: Silero TTS (русский) + собственная цепочка эффектов,
  превращающая обычный голос в механический голос GLaDOS
  (pitch-shift -> кольцевая модуляция -> флэнжер -> перегрузка -> реверб).
+ Слово активации "Гладос" + 10 секунд продолжения диалога без него.
+ Характер: обращение "сэр Марлен", приветствия по времени суток,
  вариативные реплики, поздравление в день рождения.
+ Команды: запуск приложений и игр Steam, время и дата прописью,
  заметки (в том числе из буфера обмена), напоминания с разбором русских дат,
  выключение и перезагрузка компьютера с подтверждением.
+ Резервный синтез через Windows SAPI, если не удалось поставить torch.
